Verificação opcional: o que a memoização reaproveitou?

Na memoização de F(5), os nós F(2) (sob F4) e F(3) (sob F5) vêm do cache (verde): suas subárvores inteiras deixam de ser calculadas. Consultar memo[n] é O(1); o algoritmo todo é O(n).

Moedas: do guloso ao ótimo PDF p. 15–19

Moedas são valores, em quantidade ilimitada. Objetivo: formar o alvo com o mínimo de moedas.

Verificação opcional: válida × mínima

Alvo 6 com {1,3,4}: 4+1+1 forma 6 (válida) com 3 moedas; 3+3 forma 6 com 2 moedas (mínima). O guloso pega a maior moeda agora, sem garantir o ótimo global.

Construindo solve(x) PDF p. 20–25

Contrato: solve(x) recebe o valor x e devolve a quantidade mínima de moedas para formá-lo.

solve(3) = 1 não é "3 moedas": o valor 3 se forma com 1 moeda.

Tabela p. 21, coins = {1,3,4}

A coluna "combinação" é adaptação didática.

Mesa de escolhas — exemplo p. 22: solve(10) = 3, pois 3+3+4. Qual pode ser a primeira moeda? 1, 3 ou 4.
Explicação concreta: você paga o alvo com moedas de uma gaveta sem fim. Coloque UMA moeda no balcão (essa é a +1 moeda). Ainda resta pagar um valor menor: a mesma pergunta, só que menor — o melhor jeito de pagar o restante (é o solve do restante). Repita para cada moeda possível e fique com o menor total. Atenção: com moeda 1 sobre o restante 6, não são seis moedas de 1 — o melhor para 6 é 3+3.
Fórmula (p. 24)
solve(x) = min(solve(x − 1) + 1,
solve(x − 3) + 1,
solve(x − 4) + 1)

Caso-base (p. 25): solve(0) = 0. Cadeia: solve(10) = solve(7)+1 = solve(4)+2 = solve(0)+3 = 3 (moedas 3, 3 e 4; a ordem não importa).

O min compara a quantidade TOTAL de moedas de cada opção, não o valor das moedas.

Verificação opcional: separar valor e quantidade

Alvo 10, moeda inicial 3: ALVO 10 · MOEDA 3 · RESTA 10−3 = 7 · solve(7) = 2 moedas (3+4) · TOTAL = 1 + 2 = 3 moedas.

Dos subproblemas ao código PDF p. 26–28

Adaptação executável: a simulação roda em JavaScript equivalente, com INF = 1e9 (sentinela seguro). Não é o código literal do slide. INF = impossível ou ainda não encontrado; x < 0 = tentativa inválida; x == 0 = base. best = min(best, solve(x-c)+1) = comparar a opção atual com a melhor conhecida. Em C++, ready[] começa em false.

Síntese e 1034 PDF p. 29

Em uma tela
  • PD guarda respostas de subproblemas para não refazer trabalho.
  • Top-down = recursão + cache (ready/value); bottom-up = tabela dos menores para os maiores (value[i]).
  • solve(x) = mínimo de moedas para formar x; solve(x-c)+1 = restante + a moeda escolhida; min escolhe a melhor opção.
  • Caso-base: solve(0)=0; x<0 devolve INF.
